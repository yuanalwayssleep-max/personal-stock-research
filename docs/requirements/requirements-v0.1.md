# A 股个人量化投研系统需求规格说明书 v0.1

## 1. 项目概述

本系统是一个面向个人投资者的 A 股量化投研系统，核心目标是通过数据采集、因子构建、机器学习建模、股票预测、组合构建、交易计划生成、交易纪律管理和复盘分析，形成一套可验证、可迭代、可执行的投资决策闭环。

第一阶段重点覆盖：

```text
日频数据 + 量化选股 + 中短周期持有 + 组合管理 + 交易纪律 + 复盘闭环
```

## 2. 核心业务流程

### 2.1 量化选股流程

```text
获取 A 股股票池
-> 剔除不可交易股票
-> 获取历史行情和财务估值数据
-> 数据清洗
-> 计算因子
-> 构建训练标签
-> 训练模型
-> 预测未来收益/排名
-> 输出股票分数
-> 过滤风险股票
-> 生成候选股票池
```

### 2.2 组合构建流程

```text
候选股票池
-> 根据模型分数排序
-> 加入行业约束
-> 加入单票仓位约束
-> 加入流动性约束
-> 加入市场环境判断
-> 生成目标组合
-> 输出建议仓位
```

### 2.3 交易计划流程

```text
目标组合
-> 对比当前持仓
-> 判断买入/加仓/减仓/卖出
-> 生成交易计划
-> 检查交易纪律
-> 等待人工确认
-> 记录实际执行
```

### 2.4 复盘流程

```text
交易执行结果
-> 持仓收益跟踪
-> 组合表现统计
-> 模型预测验证
-> 交易纪律检查
-> 归因分析
-> 形成复盘结论
-> 优化模型和策略
```

## 3. 功能需求

### 3.1 股票池管理模块

目标：管理系统可交易和可研究的 A 股股票范围。

功能需求：

- 支持获取 A 股股票列表。
- 支持记录股票代码、名称、交易所、行业、上市日期。
- 支持标记 ST、退市、停牌、次新股等状态。
- 支持设置全 A、沪深 300、中证 500、中证 1000、自定义股票池。
- 支持自定义排除股票。
- 支持查看当前可交易股票数量。

基础过滤规则：

- 剔除 ST、*ST 股票。
- 剔除退市整理股票。
- 剔除上市不足 120 个交易日的股票。
- 剔除停牌股票。
- 剔除成交额过低股票。
- 剔除涨跌停不可交易股票。

### 3.2 数据管理模块

目标：为模型训练、选股和复盘提供稳定数据基础。

数据类型：

| 数据类别 | 说明 |
| --- | --- |
| 股票基础数据 | 代码、名称、交易所、行业、上市日期 |
| 日线行情数据 | 开盘、最高、最低、收盘、成交量、成交额 |
| 复权行情数据 | 前复权或后复权价格 |
| 指数数据 | 沪深 300、中证 500、中证 1000、创业板指等 |
| 行业数据 | 申万或中信行业分类 |
| 财务数据 | 营收、净利润、ROE、毛利率、负债率等 |
| 估值数据 | PE、PB、PS、市值、股息率 |
| 交易状态数据 | 停牌、涨停、跌停、是否可交易 |

数据质量需求：

- 检查缺失值、异常价格、成交量异常和复权价格连续性。
- 检查财务数据发布日期，避免未来函数。
- 检查股票是否在历史时点真实存在。
- 检查指数数据是否完整。

### 3.3 因子计算模块

目标：基于行情、财务、估值和流动性数据构建模型输入特征。

第一阶段因子类别：

| 因子类别 | 示例 |
| --- | --- |
| 动量因子 | 5日收益、10日收益、20日收益、60日收益 |
| 反转因子 | 短期跌幅、超跌反弹信号 |
| 波动率因子 | 20日波动率、60日波动率 |
| 成交量因子 | 换手率、成交额变化、量比 |
| 流动性因子 | 日均成交额、换手率稳定性 |
| 趋势因子 | 均线排列、价格相对均线位置 |
| 估值因子 | PE、PB、PS、市值 |
| 质量因子 | ROE、毛利率、净利率、资产负债率 |
| 成长因子 | 营收增速、利润增速 |
| 市场相对因子 | 相对沪深300/中证500强弱 |

因子处理需求：

- 支持缺失值处理、极值处理和标准化。
- 支持记录因子版本。
- 支持回看每只股票某日的因子值。
- 后续支持行业中性化和因子有效性分析。

### 3.4 标签构建模块

目标：为机器学习模型构建预测目标。

第一阶段推荐主标签：

```text
future_excess_return_20d
```

辅助标签：

```text
top_quantile_20d
```

可选标签：

| 标签 | 说明 |
| --- | --- |
| future_return_5d | 未来 5 日收益率 |
| future_return_10d | 未来 10 日收益率 |
| future_return_20d | 未来 20 日收益率 |
| excess_return_20d | 未来 20 日相对基准超额收益 |
| top_quantile_20d | 是否进入未来 20 日收益前 20% |
| outperform_index_20d | 是否跑赢指定指数 |

### 3.5 模型训练模块

目标：使用历史数据训练股票预测模型，对未来一段时间股票表现进行评分。

第一阶段模型：

| 模型 | 作用 |
| --- | --- |
| 基线模型 | 用于对照，验证机器学习是否有提升 |
| LightGBM 模型 | 第一阶段主力预测模型 |

模型输出字段：

| 字段 | 说明 |
| --- | --- |
| trade_date | 预测日期 |
| stock_code | 股票代码 |
| stock_name | 股票名称 |
| model_version | 模型版本 |
| score | 模型分数 |
| rank | 当日排名 |
| percentile | 分位数 |
| signal | 入选/观察/剔除 |
| expected_holding_days | 建议持有周期 |
| top_factors | 主要贡献因子 |
| risk_flags | 风险标签 |

模型训练要求：

- 严格避免未来函数。
- 使用滚动训练或时间切分。
- 不允许随机打乱时间序列后训练测试。
- 区分训练集、验证集、测试集。
- 记录模型版本、训练数据区间、特征版本和标签定义。

模型评估指标：Top N 平均收益、Top N 胜率、Top N 超额收益、Rank IC、IC 稳定性、最大回撤、年化收益、夏普比率、换手率、盈亏比和分层收益。

### 3.6 选股模块

目标：根据模型预测结果和交易过滤规则生成候选股票池。

候选股票池分层：

| 层级 | 说明 |
| --- | --- |
| 强推荐 | 模型分数靠前，风险过滤通过，可进入组合 |
| 观察 | 模型分数较高，但价格或风险条件未满足 |
| 剔除 | 模型分数不足或触发风险规则 |
| 持有复评 | 当前持仓，需要判断继续持有或卖出 |

选股输出字段：排名、股票代码、股票名称、行业、模型分数、分位、推荐状态、建议动作、建议仓位、买入条件、止损规则、止盈/调仓规则、风险标签。

### 3.7 组合管理模块

目标：从候选股票池中构建符合风险约束的投资组合。

第一阶段默认组合规则：

| 参数 | 默认值 |
| --- | --- |
| 最大持股数量 | 10 只 |
| 最小持股数量 | 5 只 |
| 单票最大仓位 | 10% |
| 单票最小仓位 | 3% |
| 单一行业最大仓位 | 30% |
| 默认总仓位 | 60%-80% |
| 调仓频率 | 每周一次 |
| 持有周期 | 10-20 个交易日 |
| 基准指数 | 中证 500 或中证 1000 |

组合输出：当前组合、目标组合、买入清单、卖出清单、加仓清单、减仓清单、目标仓位、当前仓位、仓位差额、行业分布和组合风险提示。

### 3.8 交易计划模块

目标：将模型和组合结果转化为可执行的交易方案。

交易计划类型：买入计划、加仓计划、减仓计划、卖出计划、止损计划、止盈计划、调仓计划。

交易计划字段：计划编号、生成日期、股票代码、股票名称、动作、原因、模型版本、策略版本、模型分数、目标仓位、当前仓位、参考价格、最高可接受买入价、止损价、止盈规则、预计持有周期、失效条件、纪律检查结果、状态。

### 3.9 交易纪律模块

目标：约束实际交易行为，减少随意交易和情绪化交易。

交易前检查：

- 是否来自系统交易计划。
- 是否超过单票、行业和总仓位上限。
- 是否买入风险过滤股票。
- 是否追高超过最高买入价。
- 是否在计划失效后买入。
- 是否对同类股票重复暴露过高。

交易后标记：合规交易、轻微偏离、严重偏离、非系统交易、纪律失败。

### 3.10 交易记录模块

目标：记录交易计划、实际执行和结果，为复盘提供依据。

记录内容：

- 交易前计划：计划 ID、模型版本、策略版本、目标仓位、计划价格、止损止盈规则、交易原因。
- 交易执行：执行日期、成交价格、成交数量、成交金额、手续费、滑点、是否按计划执行、偏离原因。
- 持仓跟踪：当前价格、收益率、浮盈浮亏、当前模型分数、是否触发止损/止盈。
- 交易结束：卖出日期、卖出价格、实际收益率、持有天数、是否跑赢基准、模型判断是否正确、执行是否合规、复盘结论。

### 3.11 复盘模块

目标：定期评估模型、组合和交易执行质量，形成持续迭代机制。

复盘分层：

- 单笔交易复盘：评估信号来源、计划执行、收益结果、基准对比、纪律问题和优化建议。
- 周度组合复盘：评估组合收益、超额收益、最大回撤、行业分布、贡献股票、拖累股票和下周调仓建议。
- 月度模型复盘：评估 Top N 表现、胜率、Rank IC、分层收益、行业差异、市场环境差异和是否需要重新训练。

## 4. 非功能需求

- 数据可靠性：数据应可追溯，更新失败应提示，关键数据应可重新计算。
- 可解释性：入选股票、模型版本、交易计划和复盘结论应可追溯。
- 可维护性：数据、因子、模型、策略应模块化，模型版本和策略版本应分离。
- 性能要求：日频更新和预测应在可接受时间内完成，页面查询不应明显卡顿。
- 安全与隐私：持仓和交易记录应本地或私有化保存，支持导出和备份。

## 6. 推荐默认配置

```text
市场范围：A 股
股票池：全 A 股，剔除 ST、停牌、上市不足 120 日、低流动性股票
数据频率：日频
预测周期：未来 20 个交易日
调仓频率：每周一次
主标签：未来 20 日相对收益
辅助标签：未来 20 日是否进入收益前 20%
模型：基线模型 + LightGBM
选股数量：Top 30 候选
组合持股：10 只
单票最大仓位：10%
单行业最大仓位：30%
总仓位：60%-80%
止损规则：单票亏损 6%-8% 或模型信号失效
止盈规则：盈利 12%-15% 后移动止盈，或模型排名跌出阈值
基准指数：中证 500 或中证 1000
复盘频率：每周组合复盘，每月模型复盘
```
