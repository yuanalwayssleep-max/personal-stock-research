# A 股个人量化投研系统 MVP 开发路线图 v0.1

## 1. 路线图目标

本路线图将第一阶段需求拆分为 4 个 MVP 迭代，目标是逐步打通以下闭环：

```text
数据 -> 因子 -> 模型 -> 选股 -> 组合 -> 交易计划 -> 执行记录 -> 复盘
```

优先级原则：先建立可验证的数据和模型基础，再构建组合与交易计划，最后完善交易记录和复盘闭环。

## 2. MVP-1：数据与因子基础

### 2.1 目标

先把数据地基打好，确保系统能够生成可靠的可交易股票池和基础因子表。

### 2.2 交付内容

- A 股股票列表。
- 日线行情数据。
- 指数数据。
- 基础过滤规则。
- 基础技术因子。
- 基础估值因子。
- 因子数据表。
- 数据质量检查。

### 2.3 关键任务

- 建立股票基础数据结构。
- 建立日行情数据结构。
- 建立指数数据结构。
- 实现 ST、停牌、上市不足 120 日、低流动性过滤。
- 实现动量、波动率、成交额、均线相关因子。
- 实现缺失值和异常值检查。
- 输出某交易日全市场因子快照。

### 2.4 验收标准

- 能生成每日可交易股票池。
- 能识别 ST、停牌、流动性不足股票。
- 能计算基础因子。
- 能输出某日全市场因子表。
- 能生成数据质量检查结果。

## 3. MVP-2：模型训练与选股

### 3.1 目标

建立初版预测模型，输出股票分数、排名和 Top N 候选股票池。

### 3.2 交付内容

- 标签构建。
- 基线模型。
- LightGBM 模型。
- 模型训练脚本。
- 模型评估报告。
- 每日或每周预测结果。
- Top N 候选股票池。

### 3.3 关键任务

- 构建 future_excess_return_20d 标签。
- 构建 top_quantile_20d 辅助标签。
- 建立时间切分训练、验证、测试流程。
- 建立基线模型。
- 建立 LightGBM 模型。
- 输出模型分数、排名、分位和信号。
- 评估 Top N 平均收益、胜率、超额收益和 Rank IC。
- 建立模型版本记录。

### 3.4 验收标准

- 能完成历史训练。
- 能输出模型分数和排名。
- 能生成 Top N 候选股票池。
- 能评估 Top N 收益和胜率。
- 能对比基线模型。
- 能避免明显未来函数。

## 4. MVP-3：组合与交易计划

### 4.1 目标

把选股结果转化为可执行的组合和交易方案。

### 4.2 交付内容

- 组合构建规则。
- 目标组合生成。
- 仓位建议。
- 买入、卖出、加仓、减仓清单。
- 交易计划生成。
- 纪律检查。

### 4.3 关键任务

- 实现 Top 30 候选股票池到目标组合的筛选。
- 实现持股数量约束，默认 10 只。
- 实现单票最大仓位 10%。
- 实现单行业最大仓位 30%。
- 实现当前持仓和目标持仓对比。
- 生成买入、卖出、加仓、减仓动作。
- 生成交易计划字段。
- 检查仓位、行业、价格、信号失效等纪律规则。

### 4.4 验收标准

- 能根据候选股票池生成目标组合。
- 能输出每只股票建议仓位。
- 能生成买入、持有、减仓、卖出清单。
- 能生成明确交易计划。
- 能标记违反纪律的交易计划。

## 5. MVP-4：交易记录与复盘

### 5.1 目标

建立计划、执行、结果和复盘的闭环。

### 5.2 交付内容

- 交易执行记录。
- 持仓跟踪。
- 单笔交易复盘。
- 周度组合复盘。
- 月度模型复盘。
- 执行偏差分析。

### 5.3 关键任务

- 建立交易执行记录结构。
- 记录实际成交价格、数量、金额、手续费和滑点。
- 记录是否按计划执行及偏离原因。
- 计算持仓收益、组合收益和基准收益。
- 标记止损、止盈和模型信号失效。
- 输出单笔交易复盘。
- 输出周度组合复盘。
- 输出月度模型复盘。
- 统计模型 Top N 后验表现。

### 5.4 验收标准

- 能记录计划和实际执行差异。
- 能统计组合收益、回撤和胜率。
- 能评估模型 Top N 表现。
- 能标记交易纪律问题。
- 能输出复盘结论。

## 6. 推荐默认参数

| 参数 | 默认值 |
| --- | --- |
| 市场范围 | A 股 |
| 股票池 | 全 A 股过滤后股票池 |
| 数据频率 | 日频 |
| 预测周期 | 未来 20 个交易日 |
| 调仓频率 | 每周一次 |
| 主标签 | 未来 20 日相对收益 |
| 辅助标签 | 未来 20 日是否进入收益前 20% |
| 模型 | 基线模型 + LightGBM |
| 候选股票数量 | Top 30 |
| 组合持股数量 | 10 只 |
| 单票最大仓位 | 10% |
| 单行业最大仓位 | 30% |
| 总仓位 | 60%-80% |
| 止损规则 | 单票亏损 6%-8% 或模型信号失效 |
| 止盈规则 | 盈利 12%-15% 后移动止盈，或模型排名跌出阈值 |
| 基准指数 | 中证 500 或中证 1000 |
| 复盘频率 | 每周组合复盘，每月模型复盘 |

## 7. 待确认决策

- 持有周期最终选择 10 日、20 日还是 60 日。
- 调仓频率最终选择每日、每周、双周还是每月。
- 基准指数选择中证 500 还是中证 1000。
- 数据源选择 Tushare、AkShare、BaoStock、聚宽、RiceQuant 还是本地 CSV。
- 第一阶段是否需要前端页面，还是先用命令行和报表文件验证闭环。
