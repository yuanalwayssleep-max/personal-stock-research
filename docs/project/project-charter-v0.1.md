# A 股个人量化投研系统项目章程 v0.1

## 1. 项目名称

A 股个人量化投研与组合管理系统。

## 2. 项目定位

本项目面向个人 A 股投资者，建设一个以机器学习选股模型为核心的个人量化投研系统。系统通过数据采集、因子构建、模型预测、股票筛选、组合构建、交易计划、纪律检查和复盘分析，形成可验证、可迭代、可执行的投资决策闭环。

系统第一阶段定位为：

```text
A 股日频量化选股 + 组合管理 + 交易方案 + 执行记录 + 复盘闭环
```

系统不定位为实时行情终端、高频交易系统、自动交易机器人或多资产机构投研平台。

## 3. 项目背景

个人 A 股投资过程中存在以下问题：

- 股票数量多，人工筛选效率低。
- 主观选股容易受情绪、热点和短期波动影响。
- 买入、卖出、止损、止盈缺少统一规则。
- 交易计划和实际执行缺少记录，难以评估纪律执行情况。
- 盈亏结果难以区分是模型问题、策略问题、市场问题还是执行问题。
- 复盘不系统，无法持续沉淀可优化的投资方法。
- 投资组合缺少统一仓位、行业和风险约束。

因此，需要一个结构化系统将“选股、组合、交易、记录、复盘、迭代”标准化。

## 4. 项目目标

### 4.1 总体目标

构建一个专注于 A 股市场的个人量化投研与组合管理系统，通过机器学习模型对股票未来表现进行评分和排序，并基于模型结果生成候选股票池、组合配置方案、明确交易计划和复盘报告，提高选股质量、交易纪律和投资决策一致性。

### 4.2 第一阶段目标

第一阶段打通以下闭环：

```text
A 股数据 -> 数据清洗 -> 因子构建 -> 模型训练 -> 股票预测 -> 股票筛选 -> 组合构建 -> 交易计划 -> 交易记录 -> 复盘评估 -> 模型与策略迭代
```

### 4.3 业务目标

- 建立 A 股量化选股框架。
- 建立机器学习股票预测模型。
- 每日或每周生成可交易候选股票池。
- 根据模型分数和风险约束构建投资组合。
- 为每只入选股票生成明确交易方案。
- 记录每笔交易的计划、执行、偏差和结果。
- 复盘模型有效性、组合表现和交易纪律。
- 持续提高系统的胜率、收益风险比和执行一致性。

## 5. 项目范围

### 5.1 第一阶段范围内

- A 股股票池管理。
- 日线行情、指数、行业、基础财务和估值数据管理。
- 数据清洗与质量检查。
- 因子计算与训练标签构建。
- 基线模型和 LightGBM 模型训练。
- 模型预测、股票评分和排序。
- 股票筛选与风险过滤。
- 组合构建和仓位建议。
- 交易计划生成和交易纪律检查。
- 交易执行记录、持仓跟踪和复盘分析。

### 5.2 第一阶段范围外

- 自动实盘下单。
- 高频交易、分钟级和 Tick 级行情。
- 港股、美股、基金、期货、期权等其他资产。
- 新闻情绪、研报文本、龙虎榜、社交媒体等另类数据。
- 复杂多策略组合平台。
- 手机 App、多用户权限系统和机构级风控系统。

## 6. 关键干系人

| 干系人 | 角色 | 关注点 |
| --- | --- | --- |
| 用户本人 | 项目发起人、产品 Owner、最终使用者 | 选股效果、交易方案、复盘价值 |
| 数据源 | 外部依赖 | 数据完整性、准确性、稳定性 |
| 模型模块 | 决策支持核心 | 预测能力、稳定性、可解释性 |
| 交易记录模块 | 执行反馈来源 | 计划与执行偏差 |
| 复盘模块 | 迭代反馈机制 | 策略有效性、纪律执行情况 |

## 7. 成功标准

第一阶段验收时，系统应满足：

- 能导入或获取 A 股基础数据、日线行情和指数数据。
- 能对股票进行基础过滤和风险过滤。
- 能计算基础量化因子并构建训练标签。
- 能训练至少一个基线模型和一个机器学习模型。
- 能输出股票预测分数、排名和候选股票池。
- 能生成初步组合、仓位建议和交易计划。
- 能记录实际交易执行情况。
- 能生成周度组合复盘和月度模型复盘。
- 能统计胜率、收益率、最大回撤、盈亏比、Top N 表现和 Rank IC。
- 能区分模型错误、策略错误、市场风险和执行偏差。

## 8. 关键假设

- 投资市场只覆盖 A 股。
- 使用日频数据，不使用分钟级数据。
- 由系统生成交易计划，用户人工执行。
- 第一阶段不接入券商自动交易。
- 默认持有周期为 10-20 个交易日。
- 以模型排序选股为核心，而不是主观基本面研究。
- 目标是提高整体策略胜率和收益风险比，而不是单笔交易必胜。

## 9. 关键风险

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 数据质量风险 | 行情、复权、财务数据可能缺失或错误 | 建立数据质量检查和异常标记 |
| 未来函数风险 | 训练时误用未来信息导致回测虚高 | 严格按历史可获得数据构建特征 |
| 过拟合风险 | 历史表现好，实盘表现差 | 使用滚动验证、样本外测试和模型约束 |
| 幸存者偏差 | 只使用当前上市股票导致回测高估 | 尽量纳入历史退市股票和历史股票池状态 |
| 交易不可执行 | 涨停买不到、跌停卖不出、流动性不足 | 加入涨跌停、成交额、滑点和手续费假设 |
| 纪律执行风险 | 用户不按计划执行导致策略失真 | 记录计划与执行偏差，区分系统交易和非系统交易 |
| 胜率目标误用 | 只追求胜率，忽略盈亏比和回撤 | 同时评估收益率、回撤、盈亏比和夏普比率 |
